## Not yet tried — flagged genuinely promising, in priority order

1. **Real Ollivier-Ricci curvature** (`geometry/ricci.py`, `geometry/fast_ricci.py`'s linear-time Lin-Lu-Yau approximation for scale — exact optimal transport doesn't finish past ~16K edges, AML has ~648K). Genuinely untested weighted-graph method. **Warning**: `cyber/ricci_compression.py`'s version is NOT real curvature — it's rescaled Jaccard similarity of neighbor sets wearing curvature's name. Use `geometry/ricci.py`'s actual optimal-transport version or the honest linear-time lower bound, not that one.
2. **gray_coherence direct-vs-detour consistency** (`core/gray_coherence.py`, `core/cosmos.py`'s 2-cells, `core/two_cell_bridge.py`). Compare a direct A→C payment against a composed A→B→C route for amount/currency/timing consistency — a claimed 3-hop layering path that doesn't conserve a plausible bottleneck amount is a distinct signal from raw cycle detection. Note: amount-conservation specifically was just tested for literal cycles (`phase2_coherence.py`) and failed; this is a different comparison (direct edge vs. alternate route, not around-a-loop), still worth trying, but the flat result above is a reason for lower confidence than before.
3. **Persistent homology over an amount filtration** (`topology/persistent_homology.py`). More principled version of the SCC-any-length-cycle test already run — reports which cycles survive across a *range* of amount thresholds instead of one fixed cutoff (SCC test showed short/tight cycles concentrate risk better than the diluted giant-component "any length" version; persistence is the properly-scaled version of that finding).
4. **Dempster-Shafer combination of existing detectors** (`categorical/dempster_shafer.py`, `oracle/evidence_combination.py`). Doesn't need new features — combines degree/cycle/typology/CF scores with explicit conflict-surfacing instead of blending disagreement away. Cheap to test now that several detectors exist.
5. **2-hop collaborative filtering** (amount-weighted variant already tried and didn't help, see above — 2-hop neighborhood extension is untested). Natural extension now that CF is the leader. **Caution**: the underlying adjacency matrix has hub accounts with popularity up to 14,775 — squaring it for a full 2-hop expansion risks combinatorial blowup in memory. Needs a degree cap on intermediate nodes before attempting.
6. **Zero-threshold structural invariants** (`cyber/invariants.py`). Rules that must ALWAYS hold (e.g. implied-FX-rate consistency between Amount Paid/Amount Received/currencies), self-validated by firing rate, immune to threshold-tuning by construction. Orthogonal to everything tried so far.
7. **MIN-quantale (bottleneck) path composition** (`core/enrichment.py`, `core/category.py`). Tests capacity-style path aggregation (bottleneck amount along a chain) instead of the product/sum operators PageRank and Kan extension used — a genuinely different composition operator, direct test of whether "weighted, not just counted" matters under the right arithmetic.
8. **Yoneda relational fingerprinting** (`core/optimus.py`'s `yoneda_similarity`, sharpened by `core/formal_yoneda.py`'s provably-derived similarity threshold instead of an arbitrary cutoff). Refines the typology-catalog idea (which showed real if weak signal) into full relational-shape matching with a principled threshold.
9. **transitive_closure / multi-hop reachability, amount-diluted** (`zfc/universe.py`, `cyber/taint.py`'s fixpoint fractional-taint propagation). Full-graph fixpoint propagation of "distance/dilution from a known positive," modeling how laundered money dilutes when mixed with legitimate volume across many hops — richer than the one-hop Kan extension already tried.

## No honest mapping — don't force these

Confirmed across all four passes, for AML's actual column set (Timestamp, From/To Bank, Account, Account.1, Amount Received/Paid, Receiving/Payment Currency, Payment Format, Is Laundering):

- **Anything needing motive, intent, or role** — activity theory (`categorical/activity_system.py`), game theory / Nash equilibria (`game/nash.py`, `game/open_games.py`, `oracle/game_strategy.py`) — WHY.md already names this exact gap for the cyber data, and AML has no payoff/motive field either. Don't substitute dollar amount for "payoff" — it isn't one.
- **Anything needing text or embeddings** — `oracle/coherence.py`'s antonym-pair NLP coherence check, `cyber/semantic_event_matcher.py`. No text fields exist in the AML schema.
- **Cryptographic number theory** — `categorical/prime_theory.py`, `zfc/prime_enhancement.py`, `cyber/elliptic_curves.py`, `cyber/crypto_analysis.py`. No cryptographic material (keys, signatures, nonces) anywhere in AML data. (Same conclusion applies to the cyber authentication-log data — see WHY.md: "time, users, hosts, type, success. That is all.")
- **Time-window-based methods** — `topology/temporal_sheaves.py`, `cyber/attack_chain_strategies.py`, `cyber/attack_propagation_ca.py`'s hardcoded windows. This is WHY.md's own named trap ("a threshold in disguise," killed two detectors). Timestamps are unused in this project by design until a non-arbitrary justification exists.
- **Software-composability type systems** — `core/typed_capabilities.py`, `game/open_games.py`'s lens-based composition. About wiring software components together; no analogous question exists for a transaction ledger.
- **HoTT proof-theoretic induction** — `hott/path_induction.py`. A formal-verification principle for proving equalities hold universally, not a data-analytic technique.

## The clearest lesson, repeated across all four passes

Every elaborate method that lost, lost the same way: a hand-authored constant stood in for a measured quantity (`cyber/kan_filling.py`'s guessed confidences, `cyber/stealth_scoring.py`'s invented stealth scores), or a simple metric got relabeled as something more sophisticated than it was (`cyber/ricci_compression.py` calling Jaccard similarity "curvature"). Every method that held up replaced a guess with something *measured* — empirically from the data, or self-referentially per-entity rather than assumed-global (`cyber/host_baseline.py`'s per-host baseline fixing `cyber/telemetry_coherence.py`'s broken global-ratio assumption). The second lesson: a method can look like real structure while measuring a confound one level up — `cyber/hunt_targets.py`'s apparent win evaporated under a size-matched control it added itself. Before trusting a big win here, ask what a second, more targeted control would show — not just the shuffle control already standard in this repo.
